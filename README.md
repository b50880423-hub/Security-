# Telegram Group Security Bot — Start + Help UI

Includes:
- /start security landing panel
- ADD ME TO YOUR GROUP deep-link button
- Inline HELP button
- Inline help categories
- Per-command descriptions and usage
- Existing security/moderation commands
- MongoDB persistence
- Render-ready deployment

Required environment variables:
BOT_TOKEN
MONGO_URL
MONGO_DB_NAME=telegram_security
OWNER_ID
DEFAULT_MUTE_MINUTES=60
ALERT_CHAT_ID (optional)

Keep secrets out of GitHub.
